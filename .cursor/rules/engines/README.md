# Odin engines

On-demand engines, Terminus-shaped, Odyssey-adapted. The always-on router is
`.cursor/rules/09-engine-router.mdc`. These files are `alwaysApply: false`
so only the matching engine is loaded.

| Engine | Role | Difficulty job |
|---|---|---|
| 1 ideas | Qualify the idea | Name the first-attempt trap or refuse |
| 2 novelty | Similarity | Change the problem, not the nouns |
| 3 create | Draft + bundle | Hard-first CREATE; decoys; hidden majority |
| 4 audit | Pre-zip review | Probes V/D/L/A; decorative-hardening scan |
| 5 verify | Oracle / NOP | Solvable and floored; do not ease tests |
| 6 package | `package_task.py` | All gates including difficulty heuristic |
| 7 revise | Lane router | Fairness vs harden vs reviewer; never bounce to easy |
| 8 harden | Too-easy structural | Interaction, decoys, independent hidden; no Case 6 clone |

Policy they all share: `docs/odyssey-difficulty-design.md`,
`.cursor/rules/08-difficulty-design.mdc`.
